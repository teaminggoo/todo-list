# 📝 To-Do List Web App

깔끔하고 모던한 UI를 제공하는 웹 기반 할 일 관리(To-Do List) 애플리케이션입니다.

## ✨ 주요 기능
- **할 일 추가 & 삭제**: 새로운 할 일을 추가하고 불필요한 항목은 삭제
- **인라인 편집 (수정)**: 할 일 텍스트를 더블 클릭하거나 수정(✏️) 버튼을 눌러 즉시 변경
- **상태 필터링**: 전체 / 진행 중 / 완료 / ⭐ 중요 탭으로 구분하여 확인
- **마감일 & D-Day 뱃지**: 마감 날짜를 지정하고 오늘 마감, D-Day, 기한 초과 뱃지 표시
- **실시간 검색**: 등록된 할 일을 키워드로 실시간 검색
- **완료 항목 일괄 삭제**: 완료된 항목들을 한 번에 정리
- **다크 모드 지원 (🌙 / ☀️)**: 눈이 편안한 다크 테마 지원
- **로컬 스토리지(LocalStorage) 연동**: 새로고침하거나 브라우저를 닫아도 데이터와 테마 설정 영구 보존

## 🛠️ 기술 스택
- HTML5
- CSS3 (CSS Variables 기반 반응형 & 다크모드)
- JavaScript (Vanilla JS, LocalStorage API)
